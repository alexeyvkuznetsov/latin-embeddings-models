# Контрольные модели позднего LatinISE

Дополнение к `latin-embeddings-models`, проверенная версия основы: `a231143333e2397b98cae1d34ca805fbaa2f8e80`. Распакуйте файлы в корень этого репозитория. Исходный `src/core.py` и четыре существующих ноутбука не заменяются. Исходный корпус должен быть локально доступен. Перед началом при наличии интернета можно проверить файлы: `python download_corpus.py --check-only`.

Откройте `notebooks/04_train_ablation_models.ipynb` в том же окружении, что использовалось для исходных моделей. По умолчанию три новых среза × десять seed × mc5. Для mc50 измените `MIN_COUNTS` на `(50,)` либо `(5, 50)`. При наличии прежних результатов код пропускает существующие обучения. Используются параметры исходной конфигурации, а не новые гиперпараметры.

| Срез | Исключения по ID |
|---|---|
| post180_no_vulgate | IT-LAT0001 — Vulgata |
| post180_no_justinian | IT-LAT0867 — Codex; IT-LAT0202 — Institutiones |
| post180_no_vulgate_no_justinian | все три произведения |

«Без Юстиниана» не означает «без римского права»: остаются, например, Sententiae Павла, фрагмент Codex Theodosianus и другие тексты. Исключения служат для оценки чувствительности к составу корпуса. Удаление текстов одновременно меняет размер и жанровую структуру корпуса; причинный эффект христианизации из этого не следует. Ключевые авторы и жанры требуют отдельного анализа, цитаты из Вульгаты сохраняются в других сочинениях.

По каждому срезу создаётся отдельный файл `data/slices/post180_no*.csv`, частотный словарь в `results/`, модели в `results/runs/` и `results/selected/`. Отбор — `core.choose_anchors` и `core.agreement`, 300 контрольных лемм, Top-15, средний коэффициент Жаккара; anchor-списки разные для разных срезов, но процедура одинакова. Не используются оценки целевых лемм для выбора seed. Оригинальные `results/selected/selection.csv`, `selection.json`, `results/corpus_summary.csv` не заменяются. Новые выборы сохраняются в `results/ablation/selection.csv` и `.json` с контрольными суммами. После проверки и решения вопроса лицензирования эти модели можно добавить в общий каталог моделей и использовать в репозитории конкретной статьи.

Дополнительно `results/ablation/target_counts_by_work.csv` содержит частоты 39 пилотных лемм и *gratia*, *peccatum* по произведениям; `target_counts_by_block.csv` — сводку по блокам. Частоты в базовом корпусе сверяются с опубликованными частотными словарями и числом слов и предложений. Это не проверка идентичности порядка контекстов. При несовпадении расчёт останавливается, данные не заменяются. Для автономной проверки байтов источника используйте отдельную проверку корпуса, описанную выше.

Не меняйте настройки или тексты между запусками одной серии. При их изменении архивируйте старые новые модели и пересчитайте серию; совпадение частот недостаточно для проверки идентичности обучения. Для новой серии рекомендуется прежнее окружение Gensim 4.4.0. Исходные тексты и внешние векторы не входят в дополнение.
