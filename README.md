# LatinISE: обучение статических моделей латинского языка

Простой репозиторий для гуманитарных исследователей. **Корпус уже исправлен** и лежит в `data/new_lemmatized_texts/`.

## Четыре последовательных ноутбука

1. `00_prepare_corpus.ipynb` — два хронологических среза, статистика корпуса, сохранение списков файлов.
2. `01_train_models.ipynb` — 4 серии по 10 независимых запусков CBOW (до 180 г. / 180–605 гг.; `min_count=5` и `50`).
3. `02_select_models.ipynb` — выбор представительного запуска каждой серии по сходству Top-15 соседей (Жаккар).
4. `03_validate.ipynb` — внешний тест синонимов и Opera Latina, диагностические пары, сопоставление с Лунарди.

Установка: `pip install -r requirements.txt`. Запуск в Jupyter или Google Colab (путь к проекту можно указать в первой ячейке).

## Обучение

Фиксированы CBOW (`gensim.FastText`, символьные n-граммы отключены), `vector_size=100`, `window=5`, `epochs=10`, `negative=5`, `sample=0.001`, `workers=1` и `seed=1…10`. Срезы выбираются по `date_range_end` в `data/metadata.csv`. Файлы с пометкой `data_issue` исключаются.

**Никаких автоматических правок исходных текстов, контрольных сумм и сложных манифестов.** Ноутбук 00 проверяет наличие файлов, но не их содержание с филологической точки зрения.

Тексты должны иметь *по одному предложению на строку*. При чтении леммы приводятся к нижнему регистру, `v` переходит в `u`, удаляется краевая пунктуация. Исходные тексты остаются прежними.

Программа пропускает существующие модели: это удобно при возобновлении обучения. **Если корпус или настройки обучения были изменены, вручную удалите/заархивируйте старые `.model` из `results/runs/` и повторите ноутбуки 00–03.** Автоматической проверки их совместимости нет.

Результаты каждой стадии — обычные `.csv`, которые можно открыть в Excel, плюс сохранённые модели `.model`. Таблица параметров хранится в `config/settings.json`.

## Методологические оговорки

- Медоид выбирается по устойчивости соседств, а не по внешнему тесту семантической точности.
- Десять инициализаций оценивают вариативность алгоритма, но не жанровый/авторский состав корпуса (Antoniak & Mimno, 2018).
- Тест синонимов зависит от порога частоты; для `min_count=50` охват мал.
- Сравнение с *Opera Latina* идёт лишь по общим заданиям.
- Прямые межпериодные косинусы **между векторами одной леммы** требуют выравнивания пространств; этот этап в данный репозиторий не включён.

Основные опоры: Lunardi (диссертация, 2026), Sprugnoli, Passarotti & Moretti (2019/2020), Ribary & McGillivray (2020), Antoniak & Mimno (2018). Подробности — `docs/REFERENCES.md`.
