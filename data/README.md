# Источники данных

## LatinISE

Источник лемматизированных текстов — [раздел `christianity_semantic_change/data` репозитория Barbara McGillivray / Valentina Lunardi](https://github.com/BarbaraMcG/latinise/tree/39fe6e72bbec494dfc37693033be8e51622c73ba/christianity_semantic_change/data), версия `39fe6e72bbec494dfc37693033be8e51622c73ba`. Исходный корпус: [LatinISE, LINDAT/CLARIAH-CZ](http://hdl.handle.net/11372/LRT-6140). Методика: V. Lunardi, *Computational approaches to semantic change: the case of Christian Latin* (2026).

При сопоставлении Git-деревьев 24.11.2026 все 1153 файла `new_lemmatized_texts/` рабочей копии (`10bb441634d699b60aa8e64a0d583d63c7b293c0`) совпали с исходными Git blob SHA; пропущенных и изменённых файлов не было. Это проверка опубликованной копии текстов, а не филологическая валидация лемматизации и не доказательство того, что байты исторической обучающей копии были теми же.

Из корня проекта:

```sh
python download_corpus.py
python download_corpus.py --check-only
# При необходимости поиска контекстов:
python download_corpus.py --with-originals
```

Программа проверяет идентичность локальных файлов и скачивает только отсутствующие. Она не меняет имеющиеся тексты или метаданные. Сетевой доступ к GitHub нужен и при проверке, чтобы получить дерево зафиксированной версии. Разметка текстов остаётся исходной. Нелемматизированные тексты имеют 1153 файла; сопоставление контекстов между версиями требует отдельной проверки.

`metadata.csv` — собственная рабочая таблица проекта, не идентичная таблицам Лунарди. Содержит дополнительные сведения, включая `author_religion`, `data_issue`, `tokens`. Эти поля не следует автоматически заменять предсказаниями классификатора из актуальной таблицы Лунарди. Хронологический отбор определяют `date_range_end` и отсутствие `data_issue`. `slices/` содержит уже опубликованные списки обучающих произведений.

## Внешние ресурсы

- Тест синонимов: CIRCSE, [Lemma-Embeddings-for-Latin](https://github.com/CIRCSE/Lemma-Embeddings-for-Latin); `benchmark/README.md`.
- Модель Opera Latina (LiLa): `reference_models/README.md`. Ноутбук 03 получает оба ресурса при отсутствии локальных файлов.
- Августин и Фома Аквинский: ссылки и параметры в `../models_catalog.csv`; загрузка для тематических исследований производится в их собственных репозиториях.

## Распространение

Публичная доступность исходных данных не равнозначна разрешению на их повторное распространение. До выяснения условий лицензирования рекомендуется не публиковать копии текстов и сторонних моделей, а загружать их у разработчиков. Условия распространения производных моделей LatinISE и рабочей таблицы метаданных также требуют проверки. Удаление уже отслеживаемых файлов из текущего дерева и добавление в `.gitignore` не удаляет их из истории Git. Очистка истории — самостоятельная операция после резервного копирования и согласования.
